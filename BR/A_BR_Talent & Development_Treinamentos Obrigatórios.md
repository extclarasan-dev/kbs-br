TÍTULO DA KL:
A_BR_Talent & Development_Treinamentos Obrigatórios
RESUMO:
Os treinamentos obrigatórios no trabalho visam garantir a conformidade com normas de segurança, saúde e legislações trabalhistas, além de promover o desenvolvimento profissional. 
REQUISITOS:
Ser colaborador MELI e estar logado na plataforma do treinamento
PROCEDIMIENTO:
Como acessar o Learning Hub?
👉 Você acessa via MELI TOOLs ou pelos links abaixo: 
🤩 Para aprender (como aluno): https://learninghub-int.mercadolibre.com/ 
🤩 Para criar conteúdo de aprendizagem:  Faça login uma vez como aluno e solicite permissão para criação de conteúdo https://learninghub-studio-int.mercadolibre.com/ 
👉 Segue passo a passo de acesso: https://scribehow.com/shared/Como_ingresar_a_LearningHUB__qJwA-0tjTzGyrmo13VhBFw 
Estou tendo problemas com meus cursos normativos: 
Você deve informar isso através de um ticket na Plataforma de Learning Hub, no botão com o sinal de exclamação localizado na parte inferior direita de cada tela.
Compartilho este link com você para mais informações: https://wiki.adminml.com/page/3789496824624740?lang=pr 
Estou com problemas de acesso ao Learning HUB/ Tenho um problema com um curso normativo de e-learning. 
Caso você tenha dificuldades com os cursos normativos de e-learning, recomendamos seguir os seguintes passos: 
-Limpar o cache e os cookies. 
-Permitir JavaScript e pop-ups. 
Se o erro persistir, você deve reportá-lo através deste chat, escrevendo "quero falar com um agente".
Quero cancelar um curso no qual me inscrevi: 
Para cancelar a reserva do curso, você pode fazê-lo através do bot do MeliBooking. 
Ele mostrará os workshops nos quais você está inscrito e você deve procurar a opção correspondente e clicar onde diz "Cancelar".
PERGUNTAS FREQUENTES:
Estou com erro ao tentar fazer curso obrigatório no Learning Hub, o que fazer?
Referente aos erros nos cursos, caso você não consiga acessar ou concluí-lo, pedimos por favor que faça dois procedimentos ao acessar a plataforma:
-Limpar o cache e os cookies
-Permitir JavaScript e janelas pop-up (ver se o navegador apresentou uma notificação bloqueando a abertura de uma nova janela ou aba)
Não estou conseguindo concluir um treinamento obrigatório devido a erros, pode me ajudar?
Para você relatar os erros que impedem o acesso, execução ou conclusão do curso ou se você já finalizou o curso mas ainda continua como pendente, por favor escreva neste chat “Quero falar com um agente” para receber assistência.
Recebi email para fazer/concluir o curso de compliance, mas não sei onde faze-lo, pode me ajudar?
Este treinamento é obrigatório para todos os colaboradores e deve ser realizado em até 60 dias após a data de admissão. Para acessá-lo, entre na plataforma Learning HUB que vai está disponível.
📌 Se surgir alguma dúvida sobre os temas apresentados no curso, envie uma mensagem para:        compliance@mercadopago.com.br.
Seu compromisso com esse tema é fundamental!
Onde realizar os cursos normativos? 
Na MELI, contamos com alguns cursos normativos. Revise seus e-learnings pendentes na seção "Learning" no SuccessFactors.
Onde estão localizados os cursos de E-learning?
Os cursos de e-learning estão disponíveis na plataforma do Learning Hub, para que você possa treinar em diferentes tópicos.
Quais são os cursos normativos?
1- Prevenção à Lavagem de Dinheiro, ao Financiamento do Terrorismo e a Proliferação de Armas de Destruição em Massa
2- Segurança da informação
3- Código de ética
4- Como protegemos os dados pessoais no Meli?
5- Lei Geral de Proteção de Dados
6- Programa de Proteção à Propriedade Intelectual
Os cursos atribuídos devo realizá-los? 
Os cursos atribuídos são conteúdos necessários para o seu aprendizado no MELI, foram pensados para que você os complete com caráter obrigatório. Alguns desses cursos têm uma data de vencimento para serem concluídos, por isso recomendamos que você os finalize antes da mesma.
