Resumo:
Este documento descreve o processo de Avaliação de Performance Trimestral para a equipe de Fuerza de Ventas (Fintech) no Mercado Livre. Preguntas frequentes:
Como se avalia a Performance (Desempenho) para ejecutivos de cuentas?
Para os papéis de executivos de contas, o ciclo de avaliação de Performance é realizado em 4 momentos no ano, ao finalizar cada trimestre.

O que busca o processo de avaliação de performance (desempenho) trimestral?
O processo de avaliação de performance trimestral busca potencializar as pessoas e promover o princípio fundamental, a Meritocracia no MELI. Em cada trimestre avalia-se:
O QUÊ : Objetivos
COMO : Princípios Culturais

Se eu sou ejecutivo tenho que realizar a minha autoavaliação para o processo de avaliação de performance?
Não, não há uma ação concreta, como por exemplo autoavaliação, que você tenha que realizar no sistema para o processo de avaliação de performance.

Se pertenço à Fuerza de Ventas de Fintech, quando recebo feedback sobre o meu desempenho?
Promovemos uma cultura de feedback contínuo, portanto ao finalizar cada avaliação do trimestre você terá uma conversa com o seu líder, na qual poderão identificar impactos, capturar aprendizados e acordar quais são os focos daqui para a frente.
