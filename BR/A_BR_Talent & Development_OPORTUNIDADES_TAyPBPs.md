PREGUNTAS FRECUENTES:

Quais são os critérios de elegibilidade para validar a participação dos candidatos no programa de Oportunidades?

Os critérios de elegibilidade são:
- Tempo no Cargo/Meli (conforme aplicável)
Reps, Ops e Aux → 12 meses no MELI
Up to Senior Analyst → 12 meses na função
Up to Senior Manager → 18 meses na função

- Performance (Meet/Above - Aligned/Rol Model - Não estar ativo em um PIP)
Reps: 3 ciclos
Outros cargos: 1 ciclo

- ENG / EXE (caso aplicável)

- Presencialidade (Não apresentar mais de 2 desvios nos últimos 6 meses, de acordo com a pauta definida por senioridade).

- Conectividade (Não apresentar desvios de conectividade baixa nos últimos 6 meses).

- Inscrição Única (É requisito para se inscrever não estar ativo em outro processo de Oportunidades)

Qual é o percentual de Engagement/EXE que um candidato deve ter para ser elegível no programa de Oportunidades?

O requisito se aplica para líderes, tanto Non Ops (Sups & Up) quanto Ops (Team Leaders, Coordinators), que precisam ter um mínimo de 5 reportes (mínimo de 5 respostas).

Para ser elegível, a pontuação de % de favorabilidade deve ser igual ou superior a 85% em ambas as dimensões (ENG/EXE)

Como fazer alterações em uma Job Description de uma publicação em andamento?

Se a publicação estiver ativa, não é necessário pedir a modificação via Formulário. Você pode entrar em contato com o seu referente de RPO e informá-lo sobre a alteração que precisa ser feita, para que ele possa realizar a modificação. Se a publicação já não estiver ativa no site, será necessário pedir a republicação via Formulário, esclarecendo as alterações necessárias.

Como publicar uma requisição por menos dias do que foi publicado originalmente?

Para republicar uma requisição por menos dias do que foi publicado originalmente, ao republicar, esclareça o detalhe no campo “observações / mudanças”.

Como é o fluxo do processo quando há mais de um candidato selecionado para rotacionar?

Quando um candidato é rejeitado após a entrevista, o próximo passo é rejeitá-lo no sistema com o status: "Rejected by Hiring Manager - Post Interview", o que acionará os bots com as notificações de fechamento do processo (PBPs, Líderes) e, adicionalmente, enviará ao candidato o link para a pesquisa de experiência.

Como é o fluxo do processo para notificar o fechamento do processo por "Rejeição pelo Hiring Manager"?
O candidato receberá, via bot, uma notificação de fechamento do processo correspondente 7 dias úteis após ter sido movido para "Rejection by Hiring Manager".

É importante que, antes de enviar essa notificação, a pessoa já tenha sido notificada verbalmente e tenha tido seu espaço de feedback com o HM do processo.

Como é o fluxo do processo para abrir uma requisição?
O pedido de abertura de requisição é solicitado via bot de ABM.

O passo a passo é:  Criar requisição > Interna >  Motivo (Hiring plan/substituição, EHP).

Como proceder se o Hiring Manager quiser adicionar outro Hiring Manager suplente para corrigir Worksamples?

Somente o Hiring Manager pode adicionar um Hiring Manager suplente, que deve ter uma senioridade de Supervisor & UP para poder ser adicionado.

Na hora de avaliar, o Hiring Manager inicial deve selecionar a requisição e clicar no botão amarelo “Substitute” que está no canto superior direito.

Como é o fluxo do processo para o envio de Worksample?

Após o processo de verificação inicial dos candidatos por parte do TA, avança-se para a próxima etapa, que é o envio do Work Sample.

Quando o TA faz a mudança de status no sistema, o candidato recebe em tempo real a notificação via bot para acessar e realizar o Worksample atribuído.

Quanto tempo o candidato tem para realizar o Worksample?

Os candidatos têm 5 dias corridos (120h exatas) para realizar o Worksample. É possível acompanhar o estado de completude dos casos na plataforma Worksample (HR Plus).

Quando se considera uma rotação +1, lateral ou -1?
- Rotação +1: O candidato sobe um nível de senioridade. Pode ser "On Time" ou "No On Time".
Exemplo: Analista Semi Senior (8) para Analista Senior (9).

- Rotação Lateral: O candidato se move para uma posição com o mesmo nível de senioridade ou para seu equivalente estrutural. Sempre "On Time".

Exemplo: Team Leader (8) para Analista Semi Senior (8).

- Rotação -1: O candidato desce um nível de senioridade, possível apenas de áreas Non IT para IT. Sempre "On Time".

Exemplo: Analista Senior (9) para Analista Semi Senior - IT (8).

Quando se considera uma rotação On Time e No On Time?

A rotação "Real Time/On Time" significa que o movimento do candidato é efetivo no momento do impacto no SuccessFactors.
Existem três tipos de rotações que são Real Time/On Time:
-Rotações laterais (quando o candidato se move para uma posição igual ou de mesma equivalência).
-Rotações -1
-Rotações +1 que sejam On Time.

As rotações “Não On Time” ocorrem quando o candidato faz uma rotação +1, sobe um nível de senioridade, mas primeiro faz uma rotação lateral e não assume a nova senioridade ao impactar no sistema.

Como é o fluxo do processo para o envio do e-mail da rotação?

O prazo para o envio do e-mail da rotação depende do tipo de rotação:

- Sem mudança de Sociedade/Empresa: O prazo é comunicado todo mês, não sendo sempre no mesmo dia. A data exata será comunicada no canal do Google Chat "Updates Oportunidades@MELI TAs + PBPs" e no calendário de Rotações Oportunidades 2025.

- Com mudança de Sociedade/Empresa: O prazo dependerá das datas de folha de pagamento (conforme o país), sendo comunicado pelo Google Chat "Updates Oportunidades@MELI TAs + PBPs” e no calendário de Rotações Oportunidades 2025.

Como é o fluxo do processo para as rotações laterais com mudanças salariais?

As rotações laterais com mudança de estrutura terão reajuste salarial. Se alguém se mover para uma nova estrutura (ex. Operacional para TI), seu salário será ajustado para o mínimo da faixa salarial da nova posição, de acordo com seu nível de senioridade.

Como é o fluxo do processo para as rotações com mudanças no bônus target que o candidato recebe atualmente?

O bônus é calculado de forma proporcional, é pago em abril e cobre o período de janeiro a dezembro do ano anterior. Se o empregado foi transferido para um cargo com um bônus diferente, o cálculo é feito com base nos períodos trabalhados em cada função e o bônus de cada uma.

Como é o fluxo do processo após o recebimento da declaração salarial e/ou de benefícios?

Quando a declaração é enviada por e-mail, a equipe de Oportunidades fica aguardando o aviso de quando a oferta for formalmente comunicada ao colaborador. Até que isso aconteça e seja notificado para eles, não podem enviar a solicitação de rotação para a equipe de ABM para seu impacto no SSFF.

Como é o fluxo do processo de uma rotação em relação aos benefícios que permanecem ou são modificados?

Os benefícios, dependendo do país, podem estar relacionados tanto com o nível de senioridade da posição e/ou com a localização da mesma.

Se uma rotação implicar mudanças nesses aspectos em comparação com a posição atual, pode acontecer que os benefícios que o empregado recebe atualmente também sejam modificados

Como é a gestão dos benefícios por parte da equipe de Oportunidades?
Da equipe de Oportunidades, é enviado o statement onde são incluídos apenas os novos benefícios. Se o colaborador perder algum benefício no novo cargo, TA será notificado pelo mesmo e-mail de rotação para que informe ao colaborador, mas isso não será mencionado no statement.

Os statements não incluem os valores dos benefícios. Se algum benefício mudar, TA será avisado por e-mail de rotação. Se não houver mudanças no salário nem nos benefícios, o statement não será enviado.

Como é o fluxo do processo para a apresentação da declaração salarial e/ou dos benefícios ao colaborador que rota?

A apresentação fica a cargo da área de People, podendo participar TA e/ou PBP.

Como é o fluxo do processo para rotações de Oportunidades, liberação do ID em WFH e impacto da rotação no SSFF por ABM?
A equipe de Oportunidades, recebe o e-mail de rotação de TA. Verifica se a posição está correta e se há mudanças salariais ou de benefícios.

A solicitação é enviada para a equipe de ABM de segunda a quinta-feira (quando tudo estiver correto e o statement tiver sido entregue). Os pedidos da semana são processados pela ABM nas sextas-feiras, liberando o ID em WFH no mesmo dia.

O que fazer se houver um erro na posição?
Se houver um erro na informação, será conferido com o PBP (país, sociedade, etc.) e se pedirá as correções, se necessário. As rotações retroativas são tratadas da mesma forma, na primeira sexta-feira útil do mês.
