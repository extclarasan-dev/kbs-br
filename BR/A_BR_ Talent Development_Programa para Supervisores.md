TÍTULO DE LA KL:
A_BR_ Talent Development_Programa para Supervisores

RESUMEN: 
Este documento detalha o processo sobre o programa para Supervisores. 

O programa para Supervisores trata-se de um workshop destinado a um grupo de líderes selecionados de diferentes BUs, desenhado para oferecer ferramentas práticas que potencializam seu autoconhecimento, suas habilidades de liderança e a visão ecossistêmica do Meli.


REQUISITOS:

O programa para Supervisores está disponível para os seguintes job codes: 
Supervisor (80001637)
Supervisor SAdm (80001702)
Supervisor IT (80001682)
Specialist (80001722)
Specialist SAdm (80001743)

PROCEDIMIENTO:

A jornada de aprendizagem do Programa para Supervisores começará com um Launch Program virtual, no qual serão fornecidas informações aos empregados pré-selecionados, dados-chave sobre o programa e haverá a oportunidade de conhecer e se conectar com sua comunidade de aprendizagem. 

Após esse encontro, haverá um módulo presencial de 2 dias consecutivos.

Etapas do Programa para Supervisores: 

Envio de convites: Os convites para o Programa para Supervisores serão enviados aos participantes por e-mail na quarta-feira, 14 de maio de 2025, pelo responsável do programa, informando aos empregados do Meli que foram convidados a participar do programa para supervisores e fornecendo contexto sobre a modalidade do curso. Após essa comunicação, os participantes serão atribuídos à edição correspondente no Learning Hub e verão os eventos refletidos em seus calendários.

Lançamento do Programa:
O Program Launch do Programa para Supervisores tem duração de sete dias antes do início da edição. Os convidados terão um espaço de lançamento virtual do programa (com duração de 45 minutos), onde receberão contexto sobre o workshop e terão a oportunidade de se conectar com a comunidade de aprendizagem.
Início da edição presencial.
O workshop do Programa para Supervisores consiste em um módulo presencial de 2 dias consecutivos, das 9h às 18h. É importante que os convidados possam priorizar esse momento na agenda. Caso não possam comparecer ao workshop do Programa para Supervisores, escreva “quero falar com um agente”. 

Detalhe e datas das edições do workshop do Programa para Supervisores:
Edición 3 BRA: 15 y 16 de Julio de 9 a 18hs (Melicidade - Sala BR01 y BR02)

PERGUNTAS FREQUENTES:

Fui convidado(a) para participar do workshop do programa para supervisores. Por que é necessário que eu participe?

É importante sua participação no  workshop do programa para supervisores porque você foi selecionado pelo seu PBP para participar desse programa, que é destinado exclusivamente para supervisores, com o objetivo de continuar desenvolvendo seu autoconhecimento, habilidades de liderança e visão ecossistêmica do MELI.

É possível mudar a data do workshop do programa para supervisores, já que não posso comparecer na data programada?

Não é possível mudar a data do workshop do programa para supervisores, pois não temos mais edições para permitir a mudança de data. 

Caso não possa comparecer ao workshop do programa para supervisores, por favor escreva neste chat “Quero falar com um agente”

Posso ter uma reunião em algum momento durante o workshop do programa para supervisores?

Entendemos que você está com dificuldades para participar na data programada para o workshop do programa para supervisores. 

No entanto, é importante que você priorize esse momento, pois para completar sua participação é necessário estar presente em pelo menos 75% de cada encontro. Seu líder e seu PBP já foram notificados sobre o seu convite para o workshop do Programa para Supervisores.

Preciso comparecer aos dois encontros presenciais do workshop do programa para supervisores?

Sim, é necessário que você participe das duas sessões presenciais do workshop do programa para supervisores.

Tenho outra reunião com meu lead/equipe no mesmo horário do workshop do programa para supervisores. O que devo priorizar?

Seu líder está ciente do seu convite para o workshop do programa para supervisores e da importância de priorizar esse momento.

Não vejo os convites do workshop do programa para supervisores no meu Google Calendar. O que posso fazer?

Se você não vê os convites do workshop do programa para supervisores no seu Google Calendar, por gentileza, escreva neste chat “Quero falar com um agente”

Como posso me descadastrar do workshop do programa para supervisores?

Para se descadastrar do workshop do programa para supervisores, por favor, escreva neste chat “Quero falar com um agente”.
